# CaratHope API (Laravel 12, PHP 8.2)

- Run artisan with `php8.2` if the default `php` binary is older.
- Categories, subcategories, mega menu and product attribute filters: read
  `docs/CATEGORY_MENU.md` before changing anything in that area — it records the decisions
  agreed with the client (seeder-only parent categories, two-level hierarchy, menu layer).
